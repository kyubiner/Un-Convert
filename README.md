## Description
Universal Converter applications such as physical units, number systems, colors and others

## Features
- Converter Physical units (Ex : Kilometer -> Centimeter)
- Converter Number system (Ex : Binary -> Decimal)
- Converter Text case (Ex : Uppercase -> Lowercase)
- Converter Colors code (Ex : RGB -> HEX)
